# Examples

These fictional records demonstrate the assessment and log-review workflows.

- [Annual assessments](assessments/README.md): a blank spreadsheet and three completed
  examples showing improving security maturity, with import instructions.
- [Security logs](telemetry/README.md): matching annual event samples, scope manifests,
  generation instructions and the validation workflow.

Both sets can be imported from the application's **Assessments** page. Real department
imports are stored separately under the ignored `data/local/assessments/` folder.
